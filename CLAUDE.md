## Design System

The authoritative product design system is documented in `DESIGN.md`.

Before changing user-facing layout, typography, color, motion, responsive behaviour, or shared UI components:

1. Read `DESIGN.md`.
2. Reuse its tokens and component rules instead of adding page-specific visual overrides.
3. Keep motion limited to opacity and transform, and preserve the reduced-motion path.
4. Profile before introducing a new framework, runtime dependency, blur, mask, or continuous animation.
